Investment thesis

Sensors are multiplying. The missing asset is the network between them.

Defense and security customers are adding RF receivers, direction finders, radars, acoustic systems, EO/IR devices and low-cost edge sensors. Yet most remain isolated by vendor, interface and site. EwX is built around the opposite assumption: future sensing environments will be heterogeneous, distributed and software-coordinated.

What EwX is

EwX is a hardware-agnostic distributed RF sensing and intelligence layer. It is designed to ingest observations from different RF nodes, normalize them, correlate events across time and space, and publish a shared situational picture through software and APIs.

We do not need every endpoint to be EwX hardware. A third-party receiver can become an EwX node rather than an automatic competitor.

Why that matters

  • Customers can add intelligence without replacing every installed sensor
  • Coverage can grow by adding endpoints rather than one larger monolith
  • Failure of one node does not have to remove the whole sensing picture
  • Software, data quality and network effects compound above the hardware layer
Why now

Three cost curves changed at the same time.

Low-cost software-defined RF hardware, powerful edge compute and modern ML/data tooling make dense sensing networks economically possible. At the same time, contemporary defense environments reward resilience, rapid replacement and interoperability instead of dependence on a few expensive sensing points.

01 · Sensor economics

More RF capability per euro

COTS RF front ends and edge compute make it possible to deploy many useful sensing points without building every node as a bespoke high-cost instrument.

02 · Operational need

Density and resilience matter

A distributed network can trade isolated perfection for coverage, redundancy and shared context across a protected area.

03 · Software leverage

Value moves above the device

Detection logic, correlation, mapping, data history and integrations can improve across the entire installed network without replacing every endpoint.

Product architecture

Make many radios behave like one sensor.

The EwX architecture separates endpoint hardware from the network intelligence layer. That lets the sensing hardware evolve by use case while the orchestration, data model, correlation logic and customer workflow remain durable.

Market expansion

The first buyer problem is urgent and concrete: persistent RF awareness for defense and protected sites. The same network architecture can expand into broader RF situational awareness and multi-sensor infrastructure once the core distributed-sensing layer is proven.

BEACHHEAD

Detection, classification support, direction finding and multi-node location of RF activity associated with unmanned systems and other emitters.

Buyers: defense integrators, units, bases, protected sites.

Go-to-market

Start small. Prove value. Expand the same network.

The commercial motion is deliberately land-and-expand. EwX does not need a nationwide deployment to create the first contract; it needs a bounded site where a customer can measure operational value and then add nodes, locations and integrations.

Pilot

4–6 nodes, defined area, documented KPIs, decision-grade validation package.

Site deployment

Persistent monitoring, alerts, history, software support and integration into the local workflow.

Multi-site expansion

Add endpoints and locations while keeping one data model, one software layer and one operating picture.

Platform distribution

Integrators and sensor vendors can attach compatible endpoints and resell or embed the EwX intelligence layer.

Business model

Hardware enables deployment. Software and network usage scale revenue.

Reference hardware may accelerate early pilots, but the economic model is not based on owning every RF box. The aim is recurring revenue tied to active sites, connected endpoints, analytics and integrations.

Recurring revenue layers
  • Platform / site license
    Shared map, alerts, management, history and software updates.
  • Per-node / per-sensor license
    Network participation, processing, confidence metadata and orchestration.
  • Analytics / API tier
    Advanced classification, data access and integrations into external systems.
  • Enterprise support
    Deployment, calibration, SLAs, compliance and partner engineering.
Venture-scale logic

The scaling unit is the endpoint.

A customer may begin with several nodes and grow to tens, hundreds or thousands while staying on the same software and data layer. The network can expand faster than EwX could ever manufacture proprietary sensors itself.

Venture-scale logic:
Recurring revenue grows with active sites × connected endpoints × software / analytics / API value. A deployment can expand from a handful of nodes to multi-site and regional networks without requiring EwX to manufacture every sensor in that network. Pricing and endpoint economics will be validated through paid pilots.
